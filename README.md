# Waffles & Pip and the Very Suspicious Christmas Trail

Public development home for Waffles & Pip Book 9, a Christmas adventure.

- `manuscripts/book-09-the-very-suspicious-christmas-trail-manuscript.md` contains the Book 9 manuscript.
- `book.html` is the 30-page illustrated reading edition.
- `reader.json` is structured book data for future app use.
- `artwork/` contains the cover and six starter story illustrations.
- `ARTWORK.md` records the visual continuity and scene prompts.
- `index.html` is the public Book 9 landing page.
- The main Waffles & Pip bookshelf is at https://jjen1973.github.io/pip-waffles-website/.

Everything committed to this repository is public. Private print-production files belong in the separate private books repository.
